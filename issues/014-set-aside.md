# How "set aside" works

Status: idea

Setting something aside means "I don't have to think about this right now." By default, Polychrome decides when it comes back. I shouldn't have to.

## The control

A split button:

- **The main part sets it aside.** Polychrome's algorithm decides when it returns.
- **A triangle opens choices** for when I do want to say: tomorrow, next week, later.

## The algorithm

This needs working out: when does a set-aside item come back? Possible signals:

- it has become urgent (see 012)
- something it depends on has changed
- related items are being worked on, so it joins their subject
- it has waited long enough
