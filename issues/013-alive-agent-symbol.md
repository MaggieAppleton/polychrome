# A living symbol for agents

Status: idea

Agents are discs and everything else is paper rectangles (`design/01-grammar/index.html`). That split stays. The grey lettered discs are only placeholders.

I want something that feels alive: a rainbow ball, a shifting 3D shape, a blob with rainbow effects, possibly drawn with shaders.

Open questions:

- How does it show state: working, waiting on you, idle?
- Does each agent get its own colour or form? This ties into the rainbow brand (design round 3).
- It must still work at 20px in a facepile.
- How does it stay calm? It shouldn't pull the eye away from work.
- What does it cost to run: shaders on every disc, or only on large ones?
