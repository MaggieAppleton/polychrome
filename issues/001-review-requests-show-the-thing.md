# Review requests show the thing to review

Status: idea

An alert asked me to read docs/survey.md and approve the plan, with no link and no way to open it. I had to go through Finder and a separate Markdown app.

When an agent asks me to review something, the alert should show it: Markdown rendered in place, or whatever the format is.

Open questions: how agents attach the thing (a file path, a stored document, a link), and what to do with formats Polychrome can't render.
