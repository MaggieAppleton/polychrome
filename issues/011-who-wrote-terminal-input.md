# Who wrote a turn typed into the agent's terminal

Status: idea

User turns in an agent's own transcript have no sender. They can be st's wake notices ("A mission step is ready…") or something a person typed straight into the terminal. Polychrome labels them all "Input", which is honest but vague.

Mail sent through Polychrome shows the sender (`maggieappleton`), but while it's still sending it shows "You". The two should probably match.
